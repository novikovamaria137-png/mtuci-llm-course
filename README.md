Модуль 2 «Разработка приложений с LLM» · 110 минут практики.

Модель возвращает не результат, а намерение: какую функцию вызвать и с какими аргументами. Выполняет программа — отсюда белый список инструментов, проверка аргументов, разделение читающих и изменяющих операций и цикл с ограничениями.

> **Ключ доступа нужен только на последнем шаге.** Остальные шаги выполняются без него.

## Шаги

| Шаг | Что делаем | Нужен ключ |
|---|---|---|
| 0 | Восстановление каркаса уроков 2.1–2.3 | нет |
| 1 | Описание инструмента схемой и реестр | нет |
| 2 | Белый список: модель называет несуществующее | нет |
| 3 | Проверка аргументов, включая выдуманные | нет |
| 4 | Разделение читающих и изменяющих операций | нет |
| 5 | Цикл агента | нет |
| 6 | Три способа никогда не остановиться | нет |
| 7 | Инструменты для настоящей модели | да |

## Что появится в проекте

- `tools.py — реестр инструментов с проверками и цикл агента`

сам ячейками `%%writefile`; здесь они приложены, чтобы преподаватель мог сверить
результат, а код было видно без запуска.
