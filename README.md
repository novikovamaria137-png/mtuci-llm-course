Модуль 2 «Разработка приложений с LLM» · 110 минут практики.

Проверка обещания из урока 2.1: смена поставщика стоит двух строк настроек. Доказывается запуском со сверкой хеша кода. Разбирается расчёт памяти под модель, квантизация и выбор инструмента запуска.

> **Ничего не требуется:** ни ключа, ни GPU, ни установки. Кроме последнего шага — он выполняется на своей машине.

## Шаги

| Шаг | Что делаем | Нужен ключ |
|---|---|---|
| 0 | Восстановление каркаса | ничего |
| 1 | Свой OpenAI-совместимый сервер | ничего |
| 2 | Клиент из урока 2.1 против него, сверка хеша | ничего |
| 3 | Расчёт: влезет ли модель в вашу память | ничего |
| 4 | Подбор разрядности под своё железо | ничего |
| 5 | Сравнение инструментов запуска | ничего |
| 6 | Запуск настоящей модели локально | своя машина |

## Что появится в проекте

- `local.py — расчёт памяти: веса, KV-кэш, подбор разрядности`
- `fakeserver.py — минимальный OpenAI-совместимый сервер для проверок без ключа`

Файлы в папке `reference/` — эталонные версии этих модулей. Слушатель создаёт их
сам ячейками `%%writefile`; здесь они приложены, чтобы преподаватель мог сверить
результат, а код было видно без запуска.
