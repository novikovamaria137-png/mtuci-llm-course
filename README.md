Модуль 2 «Разработка приложений с LLM» · 110 минут практики.

Ответ модели начинает читать программа, а не человек. Разбирается извлечение JSON из шумного ответа, проверка формы, цикл починки и главное ограничение: схема гарантирует форму, но не содержание.

> **Ключ доступа нужен только на последнем шаге.** Остальные шаги выполняются без него.

## Шаги

| Шаг | Что делаем | Нужен ключ |
|---|---|---|
| 0 | Восстановление каркаса уроков 2.1–2.2 | нет |
| 1 | Модуль разбора со сканером, знающим про строки | нет |
| 2 | Разбор на десяти видах «грязного» ответа | нет |
| 3 | Проверка формы: все претензии за один проход | нет |
| 4 | Цикл починки с ограничением попыток | нет |
| 5 | Разбор примера из документации: форма против содержания | нет |
| 6 | Структурированный запрос к модели | да |
